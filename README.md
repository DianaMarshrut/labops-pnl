# labops-pnl

**Капсула labopsai «П&Л»** — управленческий отчёт о прибылях и убытках.
Загружаешь данные по начислениям — получаешь П&Л с маржой, долей расходов и динамикой.
Если данные только о движении денег — скажет честно, что это ДДС, а не П&Л.

## Что ты получаешь

- Отчёт о прибылях и убытках по статьям за период
- Маржа валовой прибыли, доля расходов в выручке
- Динамика месяц к месяцу (если данные за несколько месяцев)
- 3–5 ключевых выводов
- HTML-страница

## Откуда берём данные

1. **Excel или CSV** — выгрузи отчёт с начислениями из Финтабло, ПланФакт, Adesk,
   Контур.Эльбы, Моего дела или любой другой системы
2. **Google Таблицы** — гайд: https://guides.labopsai.pro/google-workspace-claude
3. **МойСклад** — если ведёшь торговый учёт там; гайд: https://guides.labopsai.pro/moysklad-claude

## Как поставить

### Claude (claude.ai или приложение)

1. «Customize» → «Plugins» → «Add marketplace» → вставь ссылку на этот репозиторий
2. «Install». Пиши «П&Л» или «P&L» в любом чате.

### Claude Code

```
/plugin marketplace add DianaMarshrut/labops-pnl
/plugin install pnl@labopsai-pnl
/plugins
```
Install → «П&Л».

### Codex

```
codex plugin marketplace add DianaMarshrut/labops-pnl
```
`/plugins` → Install → «П&Л».

### ChatGPT (через проект)

1. chatgpt.com → Проекты → Новый проект «П&Л»
2. Инструкции проекта → вставь содержимое `chat-instruction.md`
3. Новый чат → «Сделай отчёт о прибылях и убытках за квартал»

## Ограничения

- Работает с загруженными данными.
- П&Л строится по начислениям — важно правильно выгрузить данные.
- Не заменяет бухгалтера.

## Команды

- «Обнови П&Л»
- «Разбери статью [название]»
- «Сравни с прошлым периодом»
